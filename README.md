# TODO_list-app

A minimal to-do list app built with Expo and React Native.

## Stack

- Expo SDK 57
- Expo Router
- React Native / TypeScript

## Get started

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Start the dev server:

   ```bash
   npx expo start
   ```

## Scripts

- `npx expo start` — start dev server
- `npx expo run:android` / `npx expo run:ios` — run natively
- `npx expo lint` — lint
